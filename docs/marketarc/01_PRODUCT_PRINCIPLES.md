# MarketArc 产品原则

## 产品定位

MarketArc（资见 AI）面向普通投资者和非专业投研用户，帮助用户看懂财经事件、理解因果链与资产影响，并逐渐建立自己的投资判断框架。

MarketArc 不预测确定性涨跌，不荐股，不承诺收益，也不提供自动交易。

## 核心价值

内容应帮助用户完成以下认知路径：

事实 → 原因 → 机制 → 资产影响 → 市场预期 → 反方条件 → 接下来观察什么 → 可复用认知框架

目标体验是让用户产生“原来如此”，而不是只觉得“AI 总结得挺清楚”。

## 表达原则

1. 先讲人话，再介绍专业术语。
2. 第一次出现专业概念时，先解释参与者做了什么、为什么这样做、条件变化后会发生什么，再给出术语名称。
3. 流程图只能总结已经解释过的逻辑，不能用箭头替代因果解释。
4. 不把事实、推断和情景判断混为一谈。
5. 不用专业名词制造权威感，不用重复和套话制造篇幅。
6. 内容质量优先于纯速度，但性能成本必须与认知增量匹配。

## 产品优先级

- P0：用户稳定完成访问、授权、提问、Research Progress、Quick Take、Story A 和完整结果的全链路。
- P1：持续提升事实可靠性、因果完整度、新手理解度、认知增量、预期差、反方逻辑、观察框架、信息密度与来源质量。
